IMDb CSV fallback and ChronoCanon timelines

ChronoCanon imports all timelines in source watch order by default. For a single Pokémon continuity, append ?timeline=ash-continuity, ?timeline=au-movies, ?timeline=horizons, or ?timeline=specials. Confirm exact movie IDs and TV season scope using Correct match; source story blocks may span multiple seasons.

See the import format 
type,title,year,tmdb,show_tvdb,season,episode

episode,Pilot,,,263365,1,1

Types: movie, show, season, episode. IDs: tmdb, tvdb, imdb. For seasons/episodes: show_tmdb, show_tvdb, show_imdb, show_title. Episode numbers use your Plex/Sonarr ordering.
