Playlist companion

Hosted Plex Web is enabled automatically. Add a local Plex Web address to enable it for that server only. Version changes alone do not disable the companion; compatible features keep running.

    Playback bookmarks and images stay in Plex’s browser storage. Uninstalling this extension stops enhancements; it does not alter Plex playlists or watched history. Press Ctrl + Alt + Shift + L in Plex to pause or re-enable the companion and reload.
